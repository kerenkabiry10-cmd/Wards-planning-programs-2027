# תכניות עבודה 2027

אפליקציית שיבוץ למחלקות המרכז הרפואי בני ציון. מסך הבחירה זמין בכתובת הראשית ומסך הניהול בנתיב `/admin`.

## הרצה

נדרש Node.js 24. אפשר להריץ מקומית בפקודה `node server.mjs`. בפריסה יש להגדיר HTTPS ואחסון קבוע לקובץ SQLite ולגבות אותו. יש להריץ מופע אחד של השרת מול אותו קובץ. את הכתובת הראשית משתפים עם המנהלים לאחר אימות הפריסה והדוא״ל.

| משתנה סביבה | שימוש |
| --- | --- |
| `ADMIN_KEY` | סיסמת ניהול ארוכה ואקראית. |
| `DATABASE_PATH` | נתיב לקובץ במסד הנתונים באחסון קבוע. ברירת המחדל היא `bookings.sqlite`. |
| `PORT` | פורט השרת. ברירת המחדל היא 3000. |
| `RESEND_API_KEY` | מפתח לחשבון משלוח הדוא״ל. |
| `MAIL_FROM` | כתובת שולח מאומתת בשירות הדוא״ל. |
| `MAIL_TO` | כתובת קרן לקבלת הודעות שיבוץ. |

ניתן לטעון משתנים מקובץ מקומי באמצעות `node --env-file=.env server.mjs`. ההודעות נשמרות בתור במסד הנתונים ונשלחות מחדש אם שירות הדוא״ל נכשל. יש לבדוק קבלת הודעה אחת בכתובת היעד לפני הפצה.

מסך הבחירה מתעדכן מדי 2.5 שניות. מסד הנתונים אוכף שיבוץ אחד לכל מחלקה ומחלקה אחת לכל מועד. מנהלים בוחרים מחלקה מתוך הרשימה. קרן יכולה להוסיף מחלקות, לעדכן שיבוצים ולבטל אותם ממסך הניהול.
